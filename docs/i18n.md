# Wicaby i18n: French and English

Wicaby ships in French and English. French is the reference language and the fallback. The setting is `ui.language` (`'auto' | 'fr' | 'en'`, default `'auto'`): `auto` follows Windows, so `fr-*` gives French and any other locale gives English. The setting is in Settings → General → "Langue / Language". A switch applies live in both processes, with no restart.

There is no i18n library, only about 300 lines of our own code:

| File | Role |
|---|---|
| `src/shared/i18n-core.ts` | Message format (ICU-lite), catalogue flattening, language resolution. Shared by both processes. |
| `src/renderer/lib/i18n.svelte.ts` | Renderer: `t`, `tParts`, `has`, `locale`, `setLanguage`, `fmt`. |
| `src/main/i18n.ts` | Main: `t`, `language`, `onLanguageChange`, `initI18n`. |
| `src/renderer/locales/{fr,en}/<ns>.json` | Catalogues, one file per namespace and language. |
| `src/renderer/lib/format.ts` | Older helpers (`runtime`, `bytes`, `endsAt`…). They keep their signatures and now go through `fmt` and `t`. |
| `tools/checks/i18n-check.mjs` | Catalogue consistency, unknown keys, and a count of hard-coded French. |

Reference conversions to copy: `components/Toasts.svelte` (an attribute) and `components/ResumePrompt.svelte` (labels, buttons, and a placeholder wrapped in markup). On the main side, see `features/tray.ts`, `features/taskbar.ts` and `features/notify.ts`.

## API

### Renderer

```ts
import { fmt, t, tParts } from '../lib/i18n.svelte';

t('common.actions.cancel');                          // "Annuler" / "Cancel"
t('common.time.remaining', { time: '42 min' });      // "42 min restantes"
t('common.count.items', { count: 3 });               // "3 éléments" / "3 items"
```

- `t(key, params?)` is reactive. It reads `locale.current`, which is `$state`, so a template or `$derived` that calls it re-renders when the language changes.
- If a key is missing in the current language, `t` falls back to French, then to the key itself. Each missing key logs one `console.warn` in dev.
- `tParts(key)` splits a message around its `{placeholders}`, for a value that needs markup around it:

  ```svelte
  {#each tParts('player.resume.stoppedAt') as part, i (i)}{#if part.slot === 'time'}<span class="mono">{clock(ms)}</span>{:else}{part.text}{/if}{/each}
  ```

- `has(key)` is for dynamic keys that may not exist (`typeLabel` uses it for `common.types.<Type>`).
- `locale.current` (`'fr' | 'en'`) is for the rare code that must branch on the language. Prefer a message or `fmt`.
- `setLanguage(pref)` is called by `applySettings` in `stores.svelte.ts`. It also sets `<html lang>`. Don't call it elsewhere.

`fmt` wraps `Intl` and uses the active locale. French is pinned to `fr-FR`, so the output is exactly what Wicaby showed before i18n. English uses the Windows region when it is an English one (an `en-GB` clock is 24 h), and `en-US` otherwise.

| Helper | French | English |
|---|---|---|
| `fmt.number(1234.5)` | `1 234,5` | `1,234.5` |
| `fmt.date(d)` / `fmt.date(d, { weekday: 'long' })` | `12 octobre 2026` / `lundi` | `October 12, 2026` / `Monday` |
| `fmt.time(d)` | `22:41` | `10:41 PM` |
| `fmt.relative(d)` | `il y a 5 min`, `À l’instant` | `5 min. ago`, `Just now` |
| `fmt.bytes(n)` | `53,0 Mo`, `0 o` | `53.0 MB`, `0 B` |
| `fmt.speed(n)` | `53,0 Mo/s` | `53.0 MB/s` |
| `fmt.bitrate(12)` | `12 Mb/s` | `12 Mbps` |
| `fmt.duration(ms)` (runtime) | `1 h 42`, `53 min` | `1h 42m`, `53m` |
| `fmt.list(['A','B','C'])` | `A, B et C` | `A, B, and C` |
| `fmt.language('fre')` | `français` | `French` |
| `fmt.compare(a, b)` | locale-aware, numeric sort | same |

`clock()` (`1:02:03`) and `episodeCode()` (`S01E02`) are the same in both languages and stay in `format.ts`.

### Main process

```ts
import { onLanguageChange, t } from '../i18n';

new Notification({ title: t('main.notify.downloadDone') });
throw new Error(t('errors.settings.invalidFile'));
onLanguageChange(() => rebuildMyMenu());
```

- Main bundles the `common`, `main` and `errors` namespaces, through an esbuild JSON import. A new main-only namespace means a new import in `src/main/i18n.ts`.
- `t()` reads the language at call time, so a one-shot string (notification, dialog, error) only needs to call it.
- Native UI that is built once must rebuild in `onLanguageChange`. The tray menu, overlay tooltip, thumbar tooltips and jump list already do.
- An error thrown in main and shown by the renderer is translated in main, with `errors.*` keys. It reaches the UI already in the current language.

## Catalogues

- **One file per namespace and language**: `src/renderer/locales/fr/<ns>.json` and `en/<ns>.json`, loaded eagerly with `import.meta.glob`.
- **Key structure**: a file holds nested sections, and the key is `<ns>.<section>.<key>`. For example, `browse.json` `{ "home": { "rows": { "continue": "Continuer" } } }` gives `browse.home.rows.continue`.
- **Who edits what**: each extraction agent appends to its own namespace only. Anything used in several places goes in `common`.

| Namespace | Covers |
|---|---|
| `common` | Shared actions (Annuler, OK, Retour…), statuses, item types, counts, time phrases |
| `shell` | App.svelte, TitleBar, Sidebar, Sheet, Picker, generic components, BrowseMenu, ItemMenu, AddToSheet, HomeSheet |
| `onboarding` | Servers, Login, discovery, Emby Connect |
| `browse` | Home, Library, Search, Favorites, Row, Card, Hero, PlaylistItems |
| `item` | Item page: details, seasons and episodes, cast, versions, multi-server picker |
| `player` | Osd, OsdWindow, Player, ResumePrompt, stats, up next, skip intro |
| `reader` | Comic and book reader |
| `settings` | Settings.svelte panes and rows, WindowsSettings |
| `downloads` | Downloads page |
| `torrents` | TorrentsPanel, TorrentsAddSheet, TorrentSettings, `lib/torrents.svelte.ts` |
| `livetv` | LiveTv, Guide, ChannelTile, ProgramSheet, recordings |
| `vpn` | VpnPanel |
| `errors` | Error messages from main and the renderer that reach the user |
| `main` | Tray, taskbar, jump list, Windows notifications, native dialogs |

A feature may add its own namespace (the admin pages use `admin*`). It must create both language files; the checker picks them up.

**Key naming**

- Use camelCase segments, and name a key for its meaning, not its wording: `item.actions.markWatched`, not `item.marquerCommeVu`.
- Sections follow the UI: `settings.playback.skipIntro.label` and `…skipIntro.desc`; `downloads.status.queued`.
- For pairs, use `label` / `desc` (row title and description), `title` / `body` (dialogs, notifications), and `aria` (an accessible name that differs from the visible text).
- Reuse a `common.*` key only when the meaning is the same. "Enregistrer" means Save in a form and Record in Live TV, so they need two keys.

## Writing messages

1. **No concatenation.** Never build a sentence from pieces (`t('a') + name + t('b')`, or `` `${n} ${t('films')}` ``). Write one message with placeholders: `"{name} ajouté aux téléchargements"`. Word order differs between the two languages.
2. **Placeholders** are `{name}`. Both languages must use the same set; the checker enforces it. Pass raw values, already formatted when needed: `{ time: fmt.time(d) }`, `{ size: fmt.bytes(n) }`.
3. **Plurals** use ICU-lite with `Intl.PluralRules`. `#` is the formatted number, and an `other` case is required.

   ```json
   "count": "{count, plural, one {# épisode} other {# épisodes}}"
   "count": "{count, plural, =0 {No episodes} one {# episode} other {# episodes}}"
   ```

   French puts 0 and 1 in `one` ("0 épisode"); English puts 0 in `other`. Never write `élément{n > 1 ? 's' : ''}`.
4. **Select** for variants is `{kind, select, movie {…} series {…} other {…}}`.
5. **Rich text**: keep the whole sentence in one message and wrap the placeholder with `tParts`. Never put HTML in a catalogue, and never use `{@html}`.
6. **No apostrophe escaping.** `'` and `’` are literal. French text uses the typographic `’`, as the UI does today.
7. **Reactivity.** Call `t()` where it renders: in the template, in `$derived`, or in a function the template calls. A `const` at script or module top level is evaluated once and won't follow a language switch. For option lists and pane tables, either store keys (`labelKey: 'settings.panes.general'`) and call `t(labelKey)` in the markup, or build the array in `$derived`.
8. **Don't shadow `t`.** Rename loop and callback variables named `t` (`{#each toasts as toast}`, `(p: number) =>` in transitions), or the import is unreachable in that scope.
9. **Values from the server** (titles, overviews, genres, studio and person names) are never translated. Emby and Jellyfin already localize what they can for the user.
10. **Deliberate literals.** Proper nouns and technical terms (mpv, HDR10+, Dolby Vision, qBittorrent, NetBird, `S01E02`) stay in code. Language endonyms in the language picker ("Français", "English") stay as they are in both catalogues. If the checker flags a literal that is fine, put a `// i18n-ignore` comment (or `<!-- i18n-ignore -->`) on its line or the line above.

## Style

**French**

- Use the "vous" form everywhere (`Vous vous étiez arrêté à…`, `Vérifiez votre connexion`). A few current strings say "Touche…": fix them to "Touchez…" while extracting.
- Use sentence case: `Passer l’intro`, `Téléchargements terminés`. Never use Title Case or ALL CAPS.
- Use French typography: a non-breaking space before `: ; ? !` (`Toujours là ?`), the `’` apostrophe, `«  »` quotes, and `…` as a single character.

**English** (Apple TV app / Infuse tone)

- Be concise, friendly and plain. Use US spelling (`color`, `favorites`, `canceled`) and contractions where natural (`can’t`, `isn’t`).
- Capitalization follows Apple:
  - **Title Case** for short labels that name a thing or an action: buttons, menu items, row and section titles, sidebar entries, settings row labels, tabs. Examples: `Continue Watching`, `Skip Intro`, `Add to Favorites`, `Match Frame Rate`, `Sign In`.
  - **Sentence case** for anything that reads as a sentence: descriptions under settings rows, toasts, notifications, errors, empty states, placeholders. Examples: `Download complete`, `The server can’t be reached.`
  - Short words stay lowercase in Title Case unless they come first: a, an, the, and, or, of, to, in, on, at, for, by, with, from.
- Don't use exclamation marks or "please". Never use ALL CAPS ([design.md](design.md)).
- Use `…` for an action that opens more UI (`Add to Playlist…`) and for progress (`Connecting…`), as in French.
- Write numbers and times through `fmt`, never by hand.

## Checking

```sh
node tools/checks/i18n-check.mjs                        # summary
node tools/checks/i18n-check.mjs --list Osd.svelte      # every hard-coded string in matching files
node tools/checks/i18n-check.mjs --strict               # also fails when hard-coded French remains (part of npm run checks)
```

The checker:

1. Checks that the 14 namespaces exist in both languages, as valid JSON, with the same keys, no empty or non-string values, the same placeholders, and plurals that have an `other` case.
2. Resolves every literal `t('…')`, `tParts('…')` and `has('…')` key in files that import the i18n module. Dynamic keys (`` t(`x.${y}`) ``) are skipped.
3. Counts likely hard-coded French per file. It looks at markup text, user-facing attribute values and string literals; comments, log calls, imports and the locale files are skipped. The heuristics are accents, elisions (`l’`, `d'`), French function words in multi-word strings, and a list of common one-word labels.

The script exits 1 on catalogue or key errors. An extraction pass is done when its files show no hits.
